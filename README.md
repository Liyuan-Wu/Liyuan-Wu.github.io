# 个人主页（吴丽媛）

线上地址：https://liyuan-wu.github.io/

结构很简单，只有三样东西：

- `index.html` —— 整页内容 + 样式（样式写在同一文件的 `<style>` 里，改文字直接改这里）
- `images/portrait.jpg` —— 首页头像（320×320，白色补边）
- `_config.yml` —— 只用来告诉 Jekyll 别把 README 之类的文件发布出去

改完在 GitHub 网页上提交，1 分钟左右自动重建，不需要本地环境。

打印：浏览器 Ctrl+P 会走专门的打印样式（白底、单栏、不切断条目），可直接存 PDF 当简历。
